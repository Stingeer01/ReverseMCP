# Code of Conduct

ReverseMCP is a technical project. Participation requires professional, good-faith collaboration.

Be precise about evidence, assumptions, and uncertainty. Critique code and designs rather than people. Do not harass, threaten, impersonate, expose private information, or use discriminatory language. Respect licenses, authorization boundaries, and disclosure processes.

Maintainers may edit or remove comments, issues, pull requests, or contributions that disrupt the project or place users at risk. Repeated or serious violations may result in temporary or permanent exclusion from project spaces.

Report conduct problems privately to the maintainer through the contact options on the GitHub profile. Include links and enough context to evaluate the report. Reports will be handled as privately as the circumstances allow.
